Example Co. Help Centre

Any page, one script tag

This page stands in for a site that has nothing to do with Talkie. It has no bundler, no framework, and a global CSS reset that would flatten most widgets.

The round button in the bottom-right corner is the assistant. It was added with:

<script src="/dist/talkie-embed.js" defer></script>
<talkie-assistant api="http://localhost:8000" fonts="google"></talkie-assistant>

Add ?profile=it-support to this page's address to try another of the server's agent profiles.
