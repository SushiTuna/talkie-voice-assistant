Talkie Voice UI SDK

A voice assistant for any web page

Talkie adds a hands-free voice assistant to a site with one script tag. Visitors talk; it listens, answers and speaks back.

Configure it →

The demo runs on scripted answers. Switch on Live voice server above to talk to a real one.

How it works

Add one script tag and one element

Import the embed bundle and place <talkie-assistant> in your HTML.

<script src="/path/to/talkie-embed.js" defer></script>

<talkie-assistant api="https://your-voice-server"></talkie-assistant>

Your server mints a short-lived token

Your API key never reaches the browser. A tiny server route proxies the token request so only ephemeral credentials are exposed client-side.

Speech recognition, the reply and the voice run over one connection

AssemblyAI's Voice Agent API handles transcription, model reasoning and speech synthesis in a single WebSocket — no round-trips between services.

Features

Hands-free conversation or push-to-talk

Conversation mode keeps the mic open between turns so visitors just talk. Push-to-talk provides Start / Stop & Send instead.

Live transcript and word-by-word replies

The widget displays the user's utterance as it arrives, and shows the agent's answer incrementally as the voice reaches each word.

Tools: the agent can act on your page

Declare function tools and receive callbacks from the agent. Run them and send results back so the reply reflects the outcome.

Minimize without ending the call

Pressing the minimize button hides the panel but keeps the conversation alive. Tap the launcher again to restore it.

Bottom sheet on phones, floating panel on desktop

The layout attribute defaults to auto: a bottom sheet at ≤600 px wide, a floating panel otherwise. CSS properties control offset positions.

Themeable with CSS custom properties

All visual appearance flows through variables like --talkie-paper and --talkie-ink. Restyle without piercing shadow DOM.

Screen-reader announcements and reduced-motion support

An aria-live region announces state changes. The waveform and launcher waves respect prefers-reduced-motion.

No build step: a single 113 KiB script

Build the embed bundle once, host it anywhere, and add two lines of HTML. No bundler or framework required.

What you provide

  • An AssemblyAI account with an API key.
  • A token route — a few lines of server code that proxy the vendor's token endpoint and return { token, expires_in_seconds }. See the token route in the guide.
  • A persona — a system prompt and optional voice profile. Configure it on the Persona console.

Good to know

Speech starts about 5.5 s after the caller stops talking; about 3.5 s of that is the voice service's own lead-in (measured).

Not yet: there is no text-input fallback.
